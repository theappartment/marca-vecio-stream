# Marca Vecio Stream 1.3.1 - senza updater

Rimuove l'updater GitHub dall'app, dal sorgente incorporato e dall'installer. Rimuove i vecchi file del componente dalla cartella di installazione. Gli aggiornamenti si installano manualmente.

Riproduzione, pannello web, Telegram, configurazione e contenuti restano conservati. Le release precedenti rimangono disponibili.

Pacchetto per verificare la segnalazione Defender della 1.3.0 mantenendo attiva la protezione. La rimozione dell'updater non conferma la causa del blocco ne la sua risoluzione.
