# Marca Vecio Stream 1.3.0

- Aggiornamento dall'app Windows tramite le release del repository GitHub.
- Ricerca esclusivamente manuale con **Cerca aggiornamenti**; nessun controllo periodico o all'avvio.
- Download e installazione avviati con **Scarica e installa**, con verifica dimensioni e SHA256.
- Accesso al repository privato salvato con protezione Windows per l'account corrente.
- App, web server, worker Telegram e worker aggiornamenti fermati durante l'installazione.
- Sorgenti, documentazione e installer della versione originale 1.0.0 conservati per il rollback.
- Playlist mista, promo, reel, anteprime e impostazioni esistenti conservati.

La resa della dissolvenza 1.2.7 e la conferma amministratore dell'installer richiedono ancora verifica sullo schermo Windows reale.
