# Marca Vecio Stream 1.3.2 - anteprime Windows

Corregge le miniature nere nell'elenco dell'app Windows: i dati di ogni riga espongono proprieta .NET reali, inclusa l'immagine, invece di aggiungerle successivamente a oggetti PowerShell. Le anteprime delle immagini vengono caricate completamente da stream, senza dipendere dalla cache URI del controllo.

Foto, video normali, reel e sfondi rimangono modificabili con gli stessi controlli. Le miniature non bloccano i file originali e gli errori reali mostrano Anteprima non disponibile.

Verifiche: pixel visibili della miniatura nella riga e nel riquadro selezionato, foto reale nel contenitore compilato, miniatura di un MP4 reale, cache, modifica metadati ed eliminazione senza file bloccati.

Versione senza updater, con installazione manuale. Configurazione e contenuti conservati. La verifica finale sul PC con i monitor richiede l'installazione di questo pacchetto.
